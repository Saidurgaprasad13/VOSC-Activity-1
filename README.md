## 🎯 How to Play

1. Open the game in a web browser.
2. The game starts with the **Red player**.
3. Click the **Roll Dice** button.
4. A random number between **1 and 6** will appear.
5. A player needs to roll **6** to bring a token onto the board.
6. After rolling, click a highlighted token to move it.
7. If your token lands on an opponent's token, the opponent's token is sent back home.
8. ⭐ Safe cells cannot be used to capture opponent tokens.
9. Move all four tokens to the finish.
10. The first player to complete all four tokens wins the game.
11. Click **Restart** to start a new game.
